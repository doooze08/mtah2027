# Sustained control

离线基础状态机，唯一入口 `predict(observations, metadata, config)`，返回等长 H/A/D 序列。
只用球和槽位的平面位置、球队、球场尺寸、帧率；不读取任何文件，不使用身份、z、答案或裁判信号。

初始为 D。开场已有的贴球静止不建立活球控制。球心超出球场边界加 0.11 m 半径即 D。
控制候选要求距离 ≤1.3 m，球相对同一槽位的速度连续 0.32 s（25 fps 下 8 个间隔）≤3 m/s。
静止满足此条件；仅距离最近不满足。若两队同时满足，则视作争抢，不建立新控制。
确认后回溯至候选开始，只有对手确认控制才换队；飞行、擦碰和原队静止均保留球队。

接球边界采用局部速度变化修正：查看候选开始前 3 帧的入射速度，速度 >3 m/s 时，
定位相对该入射速度首次变化 >0.1 m/s 的间隔；默认取下一采样帧，若间隔起点已在脚下
0.02 m 内，则取起点。两个小阈值用于干净轨迹的采样边界，不是测量精度保证。
假设入射平面轨迹局部近似直线，控制偏移连续；噪声、曲线传球和慢速抢断可能破坏此假设。

按用户确认增加位置重启推断：控制确认后，向前追溯最多 5 s 的连续快速球轨迹，
要求发球处有同队球员。若球从场外进入，回溯至首次不再完全场外的帧；否则回溯至出脚帧。
重启推断只在 D 状态生效，不能让传球或头球提前改变已有控球球队。
它假设开场传球已获合法重启许可，单凭位置无法证明这一点。
同样，开场持续贴球静止既可能是等待开球，也可能是活球持球，位置本身无法区分。

球位置缺失时保持前状态、不插值；专项缺失处理**未处理**。未处理比赛中途裁判停表。
缺球分布尚未纳入模拟验证，可先在本地运行[缺球统计脚本](../../experiments/20261108_ball_gaps/ball_gaps.py)：
`python -m experiments.20261108_ball_gaps.ball_gaps --data-dir /path/to/data`；脚本仅输出汇总 JSON 和 Markdown。
不将窗口中的槽位视作跨片段稳定身份；真实槽位切换、追踪误差、空中贴球投影仍会造成误判。
本轮不增加缺陷模拟。干净集通过不构成真实比赛准确率证据。

参数在实验配置中冻结；`infer_restarts=false` 可关闭位置重启推断。
