# 实验记录与复现规范

同一轮算法比较使用同一份固定测试集；先生成数据，再运行所有候选。
实验定义与结论放 `experiments/<experiment_id>/`，生成的数据和报告放 `outputs/`。
模拟文件布局见 [simulation/README.md](../simulation/README.md)。

## 每次实验记录什么

- 实验目的、算法及参数、算法代码版本。
- 使用的 `dataset_id`、场景配置、生成器代码版本、依赖版本和随机种子。
- 预测和报告的保存位置。开始正式比较算法后，再加记观测文件和正确答案文件的 SHA-256。
- 分场景指标、运行检查、失效条件及结论所依赖的假设。

模拟成绩与真实比赛成绩分开说明；不能用公开五分钟答案或评分选择算法与参数。
比赛规则和具体答案路径见根目录 [AGENTS.md](../AGENTS.md) 的硬性规则。

## 复现和更换测试集

固定随机种子只是复现条件之一，不保证跨代码或依赖版本生成相同数据。
重建后逐文件比较内容；不一致时保留旧数据，调查差异，不覆盖或混用成绩。
修改生成逻辑、场景或种子时，建立新测试集标识，再让所有候选在新数据上重新运行。

已完成实验不覆盖配置；修改算法或参数另建实验。
重复运行同一数据和确定性算法用于检查复现，不算新增独立验证证据。

## 答案与访问边界

模拟算法只接收观测数据，正确标签只交给评分程序。
公开开发样例与隐藏验收数据应明确区分；隐藏验收结果不能无限次用于开发反馈。

根目录和子目录的 `AGENTS.md` 是协作约定，不是读取权限隔离。
真正隐藏答案需要独立的文件、工具和运行权限；分目录、Git 忽略或分支本身不能阻止读取。
当前项目尚未建立这种强制隔离，不将其描述成已有能力。
