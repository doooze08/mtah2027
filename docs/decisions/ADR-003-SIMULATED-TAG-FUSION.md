# ADR-003：在模拟开发阶段加入可选事件标签

状态：已接受（2026-11-09，用户在本次任务中明确确认）。调整 ADR-002 的阶段顺序，不改变输入合规边界。

先在新算法、新实验内开发坐标与自动事件标签的融合，再换不重叠种子验证；算法和参数固定后，
才输入真实全场的坐标与自动事件标签。公开五分钟只检查帧对齐、标签含义和流程，不能调参或选型。

模拟器、共享观测入口、官方评估、原算法和已完成实验均不修改。合成标签由新实验工具从
剧本合法重启事件生成，不读逐帧答案；标记允许遗漏和时间扰动。真实与模拟输入统一为事件区间，
不向算法传场景名、种子、事件精确时刻或参考状态。真实 XML 不作为开发答案。

本轮只融合定位球标记。标记为事件的强线索，坐标确定动作边界；不把整段标记复制成 D，
也不把没有标记解释为没有死球。无标签时使用严格坐标分支，接受可见犯规停表漏判。

验证包含五种缺球条件的同数据比较、标签完整／遗漏对照、独立种子的一次运行和全场格式校验。
模拟成绩不能证明真实精度；标签漏标率和时间精度尚未从独立答案验证。

2026-11-10 评审修订：用户授权共享运行器增加可选 `--tags`，删除算法专用的重复运行器。
无标签仍按原三参数入口调用；`--variant` 将对照输出放入同一实验子目录，实验收敛为开发、
独立验证、标签对照和门线检查四个。旧独立集已暴露具体问题，改为历史证据；修订版在开发后
冻结，再用预先指定的新种子 36000–36004 做一次独立检查，不据其结果继续调参。
