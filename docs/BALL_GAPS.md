# 球位置缺失统计

只统计跟踪坐标，不读答案、事件、标签或评分。开发和测试仅使用合成观测，
真实 tactical 数据由使用者在本地手动加载；本任务没有读取真实比赛文件。
统计脚本不修改模拟器、观测或算法，不生成缺球模型。

从仓库根目录执行，使用已有 Python 环境：

## 统计口径

- 任一球坐标为 NaN 就算缺球。连续缺失构成一段，按片段分别处理，不跨片段连接。
  段时长为缺失帧数 / fps；不是消失前观测到恢复后观测的时间跨度。
  首尾截断段保留已观察长度，并单独计数；同一全缺球片段可同时计入首端和尾端截断。
- 分布报告可计算数、不可计算数、P10/P50/P90/P99 和最大值；P50 即中位数，
  百分位使用 NumPy 默认的线性插值，因此帧数的百分位可以非整数。
- 缺失时长档：`<0.2`、`[0.2,1)`、`[1,5)`、`[5,30]`、`>30 s`。
  每档报告段数、缺球帧数、占全部缺球帧和占全部帧的比例。截断段按已观察长度入档。
- 每段消失前、恢复后各取一个端点，样本等权。消失前速度用该端点与前一帧，
  恢复后速度用该端点与后一帧，均按 fps 差分；不跨缺失段估计速度。
  无端点或无同侧相邻观测时，相应统计不可计算，不补 0。只有一侧可见的截断段也贡献该侧上下文。
- 坐标按 metadata 的球场长宽换算到 m。最近球员只在 x/y 均非 NaN 的槽位中计算。
  最近边线距离为 `min(y, W-y)`，最近底线距离为 `min(x, L-x)`，分别对应两条边界直线；
  场内为正、越过该方向边界为负，保留场外值。
- 速度档边界为 1/3/7/15/30 m/s；最近球员距离档边界为 1/2/5/10/20 m；
  边线和底线档边界为 0/1/3/5/10/20 m；重现跳变档边界为 1/5/10/25/50 m。
  这些档均左闭右开，首档低于首边界，末档大于等于末边界；分档比例分母为可计算样本数。
- 跳变仅取有两个端点的缺失段，为两点直线距离，不是缺球期间实际行程。
  缺球帧的可见球员数按全部 46 槽位统计，未用槽位也为缺失；不假定应有 22 人，
  不把槽位当成稳定身份。数量直方图的帧数之和等于缺球帧数。
- 空分布的百分位和最大值为 JSON `null`；空分档计数和比例为 0。
  报告不表达缺球原因、裁判状态或控球状态，不能仅凭相关统计断定遮挡原因。
