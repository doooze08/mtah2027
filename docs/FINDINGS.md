# 数据与算法认知

跨实验的数据认知汇总，每条注明**实测 / 推断 / 未知**和证据来源。详细数字留在各实验 `NOTES.md`，
决策写在 `decisions/`。新增认知时更新本文件，不在其他文档重复展开。

所有关于本场比赛的条目只来自汇总统计或定性检查，不含帧号或可直接写进算法的常数。
按 AGENTS.md，不得把本场特定帧的规则或常数写进算法。

## 跟踪数据质量

| 认知 | 类型 | 证据 |
|---|---|---|
| tactical ATD 很平滑：逐帧随机抖动约为球员 0.06 cm、球 0.33 cm（二阶差分估计，球的数值含真实踢球，是上限） | 实测 | 2026-11-08 本地一次性测量，未单独建实验 |
| 依赖逐帧速度的阈值不会被随机抖动明显干扰；平滑可能把触球瞬间的速度突变摊到数帧 | 推断 | 同上；模拟中加 1 cm 白噪声时现有算法误判约 0.2% |
| 两个半场 40.7% 的帧缺球，几乎全部在 ≥5 s 的长段内（共 150 段）；缺球时约 21 名球员仍可见 | 实测 | [缺球统计](../experiments/20261108_ball_gaps/NOTES.md) |
| 球消失前慢且有人在旁；重现时快速、贴近球员，15% 在边线外 | 实测 | 同上 |
| 长段缺球多数对应死球（数据商去掉了死球期间的球） | 推断 | 同上；Metrica 三场支持同一机制，见 [外部数据调研](research/EXTERNAL_DATA.md)第 11 节 |
| 活球期间是否也有长段缺球 | 未知 | 尚未统计 |

## 官方 D（死球）的含义

官方答案由修正后的跟踪数据中的“球死”标记机械导出（[CHALLENGE.md](../CHALLENGE.md)），不一定与规则书上的瞬间一致。
对公开五分钟内 4 段 D 的定性检查（AGENTS.md 允许用于理解标签含义；样本很少，不代表比例）：

| 认知 | 类型 |
|---|---|
| 球出界时，D 大致从球整体越线开始，与模拟的 `ball_out` 规则一致 | 定性观察 |
| 存在 D 开始时球仍在场内、正在移动的段，很可能是哨响停表 | 定性观察 |
| **死球不一定缺球**：有的 D 段球全程可见；缺球开始也可能晚于 D 开始 | 定性观察 |
| 有缺球的 D 段，D 在球重现（重启）后不久结束 | 定性观察 |
| 哨响停表时 D 的精确起点、各种情况的比例 | 未知 |

影响：仅靠“出界 + 长段缺球”只能识别部分 D；球全程可见的停表需要跟踪坐标以外的证据，见
[ADR-002](decisions/ADR-002-INPUT-SOURCES.md)。不得据此给模拟或算法加入从本场答案推出的偏移量。

## 外部数据

公开数据中没有与官方定义一致的逐帧 H/A/D 答案。SkillCorner（MIT 许可，10 fps）适合做弱标签检查；
Metrica Game 3 与本场格式相同，适合做格式和缺球检查（许可不明确）；PFF 世界杯数据暂时拿不到、许可不明。
详见 [外部数据调研](research/EXTERNAL_DATA.md)。

## 算法现状

| 认知 | 类型 | 证据 |
|---|---|---|
| `sustained_control` 在干净模拟场景（TI、HD、BP、LC、DC）上换队顺序全对，误差是带速接球时换队时刻偏 1–2 帧 | 实测（模拟） | [最终检查](../experiments/20261108_sustained_control_final/NOTES.md)；PR #7、#11 评审时的临时运行 |
| 高球从对手头顶飞过（LC01）不会被误判换队：球速快，与对手的相对速度大 | 实测（模拟） | PR #11 评审时的临时运行 |
| 缺球时沿用上一状态，因此长段死球多被标成 H/A；球可见的哨响停表也识别不了。这是当前最大的误差来源 | 推断 | 真实输出 D 仅 58,119 帧（全文件），远少于缺球加非比赛时间 |
| `dead_ball_aware` 可信标签模式在模拟最终种子 37000 的 clean/visible 组把总错误从 8.16% 降到 2.75%，ST01 从 69.1% 降到 20.0%；其余 16 子型不高于无标签分支 | 实测（模拟） | [可信标签实验](../experiments/20261111_dead_ball_trusted_tags/NOTES.md) |
| 全部漏标时与无标签分支逐帧一致；漏一半落在准确与无标签之间；标签准确时 mixed/delayed/whole 组与无标签分支相同或略好 | 实测（模拟） | 同上 |
| 活球假标签会造成错误 D：clean 组总错误 9.90%，活球判 D 为 5,790 帧；当前没有可靠的假标签剔除规则 | 实测（模拟） | 同上 |
| 真实 tactical 全场运行格式通过；D 115,934 帧（全文件；`sustained_control` 为 58,119），59 个 `SET PIECES` 用上 45 个、未匹配 14 个、推翻 0 个、球队冲突 2 个 | 实测（诊断，不代表精度） | 同上；真实运行 |
| 标签归属改为两阶段并取第一个合格候选，修复开球前普通传球抢标签、开球后接球者停球再传被误当第二次重启；55 项单元测试通过 | 实测（单元测试 + 模拟回归） | [可信标签实验](../experiments/20261111_dead_ball_trusted_tags/NOTES.md) |
| 默认可信策略只在标签真阳性时成立；真实标签的漏标、错标和可见停表精度仍未知 | 推断 | 同上；ADR-003 |
