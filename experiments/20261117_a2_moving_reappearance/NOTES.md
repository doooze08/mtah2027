# A2：长缺球结束时球已经在动

## 问题

官方 D 的含义是：有缺球的 D 段，D 在球重新出现后不久结束。本场的球常在发球后才重新
出现，出现时已经在飞。原 `dead_ball_aware` 在长缺球结束后必须看到“静止的球被身边球员
踢出”才退出 D；看不到就一直等到两名同队球员先后控球。

PR #27 的“判 D 但球可见且快”45 段中，43 段是重现时球已经在动（A2）。本实验只处理这条
路径，不把“球在动”当作任意 D 状态的兜底。

## 规则

新增开关 `end_gap_on_moving_ball`，默认 false，只在长缺球结束时触发：

1. 长缺球结束后，原逻辑没有在重现处识别到发球；球重现（若在场外，则球进入场内）后的
   第一个有限速度样本高于 `slow_speed_m_s`（3.0 m/s）。球速阈值不新增参数；球重现时慢，
   就保持原逻辑等待发球动作。
2. D 在球重现帧结束；场外重现时在球进入场内的帧结束。
3. 球队：若该停表有重合的可信 SET PIECES 标签，用标签球队；否则取 `restart_flight_s`
   内第一个确认控球的球队，并把结束帧回溯到重现/进场处。窗口内没有确认控球，保持原行为。
4. 重现到第一次控球之间再次缺球、出界，或已有发球候选，保持原行为。
5. 不跨出长缺球结束路径，不改变出界、普通可见停顿、换队帧和双人传接兜底。

开关关闭时输出与之前的逻辑逐帧一致。代码默认仍为 false；本实验的提交配置
`config.yaml` 已设为 true。没有改写旧实验配置。

## 固定验收

验收规则在运行前写定，运行后未修改：

- Metrica 每场新增“整段死球被翻成活球”的段数至多 1；三场活球判 D 不增加。
- 本场改变的段大部分落在 PR #27 的 45 段内；“球在定位球位置静止后才发出”的段基本不变。
- 模拟没有子型错误帧明显增加。

## 结论

三条验收都满足：

- Metrica 三场新增整段死球翻转均为 0，活球判 D 均下降；
- 本场 98.86% 的改变时长落在 PR #27 的 45 段内，静止定位球段没有被改变；
- 模拟没有子型变差。

因此合并代码，并在提交配置
`experiments/20261117_a2_moving_reappearance/config.yaml` 中默认启用
`end_gap_on_moving_ball: true`。代码默认值仍为 false，以保持旧实验配置的逐帧复现。

## 已知限制

- 只修 A2；A3（出界后球可见且快）和普通可见停顿没有改变。
- 球队由可信标签或窗口内第一个确认控球决定；若重现后的第一控球是对方截球，飞行段可能
  归错队。本场改变段中有 4 段跨越两队，未据此调规则。
- 若停表没有可信标签、且 `restart_flight_s` 内没有确认控球，仍保持原行为。
- 本场只有诊断，不读答案、不评分；Metrica 是弱标签，不是官方答案。
- 一条改变段不在 PR #27 的 45 段内；没有为它增加特例。
- 模拟回归只用固定集，不能证明真实比赛提升。
