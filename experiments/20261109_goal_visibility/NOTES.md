# 门线穿越后球可见时长

只读 tactical 跟踪 TXT/XML，不读控球答案、事件标签或录像。球场尺寸取元信息 105 × 68 m。
球半径近似 0.11 m，门宽 7.32 m；球整体越过门线且整体位于两门柱之间才产生平面候选。
只连接相邻且坐标完整的样本，在线段上计算越线横向位置，不跨缺球或半场插值。

```bash
.venv/bin/python -B -m experiments.20261109_goal_visibility.goal_visibility --data-dir /absolute/path/to/data
```

本地输出：`outputs/20261109_goal_visibility/crossings.csv` 和 `summary.json`，不进 Git。
本次严格筛出 1 个平面候选；到下一段缺球开始相隔 107.12 s。缺球未出现时，以半场结束作右截断。

**限制：**没有球高，不能排除越横梁，平面候选不等于已确认进球；穿越时缺球则无法检出。
下一次缺球也不一定由该穿越导致。本次没有找全进球，也没有独立复现既有的全部短延迟例子。
FINDINGS 中“进球后球可能继续可见数秒到一分钟以上，再进入缺球”结合既有本地观察，
本脚本只补充连续可见的平面候选证据，不用于选择死球参数。
